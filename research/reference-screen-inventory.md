# Reference Screen Inventory — Bachelors' Meal Manager

Reference Application: **Bachelors' Meal Manager by Red Z Apps**

| Screen ID | Screen Name | Purpose / Functionality | Key UI Elements & Controls | Status |
|---|---|---|---|---|
| SCR-01 | **Dashboard (Home)** | Central status hub for active mess and current month | Month selector, Summary KPI cards (Total Meals, Bazar Cost, Meal Rate, Fund Balance / Cash in Hand, Deposits), Member Balances carousel/list, Recent Bazar list, Quick action FABs | Confirmed |
| SCR-02 | **Daily Meal Entry** | Fast day-by-day meal logging for all active members | Date picker/arrows, Member rows with Breakfast / Lunch / Dinner counters (- / + 0.5 step), Quick 'Set 1 to All', 'Copy Previous Day', Daily total indicator, Save button | Confirmed |
| SCR-03 | **Meal Grid (Monthly Sheet)** | Spreadsheet-like matrix of the entire month | Sticky column for Member Names, sticky header for Days 1..31, cell edit popup/stepper, row totals per member, column totals per day, monthly grand total | Confirmed |
| SCR-04 | **Bazar & Expenses List** | List and filter all grocery and shared expenses | Tab filter (All, Bazar/Meal, Utilities, Feast), Date range filter, Expense cards with Buyer tag, Category badge, Amount, Action menu (Edit, Trash), Add Expense FAB | Confirmed |
| SCR-05 | **Add / Edit Expense Dialog/Screen** | Record or update an expense transaction | Date picker, Title/Description, Amount input, Category dropdown, Paid By (Buyer) dropdown, Expense Type (Meal Bazar vs Shared Utility vs Feast), Notes | Confirmed |
| SCR-06 | **Deposits & Fund Management** | Track member payments to the manager | Total collected counter, Deposit list grouped by date/member, Member deposit progress bars, Add Deposit button, Payment mode tags (Cash, bKash, Nagad, Bank) | Confirmed |
| SCR-07 | **Add / Edit Deposit Dialog/Screen** | Record a member's payment | Member selector, Amount input, Date picker, Payment Method selector, Reference / TrxID / Note input, Submit button | Confirmed |
| SCR-08 | **Members Management** | Manage mess members list and roles | Active / Archived tabs, Member profile cards (Avatar, Name, Phone, Role, Current Balance badge), Add Member button, Edit / Archive / Delete actions | Confirmed |
| SCR-09 | **Member Detail / Hisab Voucher** | Individual member comprehensive audit card | Contact info, Current month stats (Total Meals, Meal Cost, Individual Share of Utilities, Total Deposited, Net Balance status), Payment history, Meal breakdown | Confirmed |
| SCR-10 | **Monthly Hisab & Report Summary** | Group-wide monthly reconciliation statement | Final Summary Table (Member, Meals, Meal Cost, Other Cost, Total Cost, Deposit, Balance, Status), Calculation Formula Explainer, PDF Export, CSV Export, WhatsApp share text | Confirmed |
| SCR-11 | **Analytics & Visual Charts** | Graphical insights into expenses and meals | Expense breakdown Donut/Pie chart by category, Daily meal trend bar chart, Top buyers comparison, Month-over-month comparison | Confirmed |
| SCR-12 | **Trash Bin (Recovery)** | Soft-deleted records recovery | Tabs for Deleted Meals, Deleted Bazar, Deleted Deposits; Restore button; Permanent Delete button; Empty Trash option | Confirmed |
| SCR-13 | **Settings & House Config** | Mess configuration, preferences, and tools | House Profile (Name, Code, Currency), Pricing Mode selector (Auto Calculated vs Fixed Rate), Language toggle (English / বাংলা), Theme toggle (Dark / Light), Data Backup / Export, Data Restore / Import, Reset database | Confirmed |
